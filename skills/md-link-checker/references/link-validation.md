# 链接验证策略参考

## 链接类型

- **本地链接**：相对路径（如 `./docs/guide.md`、`../images/logo.png`）
- **外部链接**：HTTP/HTTPS URL（如 `https://example.com`）
- **锚点链接**：页内跳转（如 `#section-1`）

## 验证策略

### 本地链接
- 解析相对路径为绝对路径
- 检查目标文件是否存在
- 检查锚点 ID 是否在目标页面中存在

### 外部链接
- 发送 HEAD 请求检查可达性
- 对于返回 403 的链接，尝试 GET 请求并设置 User-Agent
- 内置重试机制应对临时网络问题
- 使用 LRU 缓存避免重复检查相同域名

## 常见 HTTP 状态码处理

| 状态码 | 含义 | 处理方式 |
|--------|------|----------|
| 200 | OK | 通过 |
| 301/302 | 重定向 | 跟随重定向后重新检查 |
| 403 | Forbidden | 重试 GET 请求 + User-Agent |
| 404 | Not Found | 标记为失效 |
| 5xx | 服务器错误 | 重试后仍失败则标记为不可达 |
