# 翻译格式保留指南

## Markdown 格式保留清单

翻译过程中必须严格保留以下 Markdown 元素：

- **标题层级**：`#`, `##`, `###` 等标题标记不变
- **列表**：有序列表和无序列表的缩进结构不变
- **代码块**：代码内容不翻译，仅翻译代码块外的注释文本
- **加粗/斜体**：`**bold**` 和 `*italic*` 标记保留
- **链接**：`[text](url)` 中的 URL 不变，仅翻译显示文本
- **图片**：`![alt](path)` 中的路径不变，仅翻译 alt 文本
- **表格**：保持标准 Markdown 表格格式，不使用 `<br>` 等 HTML 标签

## 排版规范

- 中文与英文之间插入空格
- 中文与数字之间插入空格
- 代码块标注正确的语言类型

## 文件命名规则

翻译后的文件命名为：`原文件名_语言标识.md`
- 中文：`article_zh.md`
- 英文：`article_en.md`
