# 输出格式参考

## 单文件分析模板

```markdown
## [文件名]

### 1. 核心概要 (Executive Summary)
单段落总结文档的核心信息和主题。

### 2. 关键要点 (Key Takeaways)
- 使用无序列表突出最重要的观点、事实或论据。

### 3. 深度解析 (Deep Analysis)
深入分析内容的意义、背景和细节。
- 突出文本中描述的底层逻辑或机制。
- 包含呈现的关键数据、统计或证据。
- 指出作者的主要立场或偏见（如适用）。

### 4. 值得关注的细节 (Notable Highlights)
值得注意的引用、独特视角、令人惊讶的信息或边缘案例。

### 5. 结论与行动建议 (Conclusion & Actionable Advice)
从内容中提炼的行动建议、推荐或后续步骤。
```

## 多文件对比分析模板

```markdown
## 综合对比分析 (Cross-Reference Analysis)

### 共同主题 (Common Themes)
识别所有文档中共享的概念、一致的观点或行业趋势。

### 差异与冲突 (Differences & Contradictions)
突出跨来源的冲突数据、不同视角或不同方法论。

### 综合结论 (Synthesis)
将所有文档的洞见融合为统一结论。
```
